# حسابات الدخول التجريبية (Demo Accounts)

> **تحذير:** هذه الحسابات للتطوير والاختبار فقط. كلمة المرور منشورة في الكود، لذلك **لا يجوز تشغيل الـ seed في بيئة الإنتاج**
> (الـ seed يتخطّى التنفيذ تلقائياً عند `NODE_ENV=production`).

المصدر: [backend/src/demo/seed.js](../backend/src/demo/seed.js) و[frontend/scripts/mock-backend.mjs](../frontend/scripts/mock-backend.mjs)
(الاثنان يحتويان على نفس البيانات، فالفرونت يعمل على أيٍّ منهما دون تغيير).

## كلمة المرور

**كل الحسابات التي لها تسجيل دخول تستخدم نفس كلمة المرور:** `Passw0rd!`

## الحسابات التي يمكنها تسجيل الدخول

| # | البريد الإلكتروني | كلمة المرور | الاسم | الدور | المنظمة / الحالة | ماذا يرى بعد الدخول |
|---|---|---|---|---|---|---|
| 1 | `admin@org.org` | `Passw0rd!` | ليلى المحمود | مديرة النظام (system admin) | «منظمة النور» — `approved` | كل شيء: لوحة التحكم، المشاريع (كلها)، الطلبات، المهام، MEAL، الملفات، التقارير، الموظفون، الأدوار، الإعدادات |
| 2 | `jalal@org.org` | `Passw0rd!` | جلال العمر | باحث ميداني | «منظمة النور» — `approved` | صلاحية `tasks.view` فقط (عرض المهام)، وهو عضو (`member`) في المشروعين التجريبيين |
| 3 | `pending@org.org` | `Passw0rd!` | سامر | مدير المنظمة | «مؤسسة قيد المراجعة» — `pending_approval` | صفحة «بانتظار الموافقة» (`/onboarding/waiting-approval`) |
| 4 | `new@org.org` | `Passw0rd!` | نورا | مديرة المنظمة | «مؤسسة جديدة» — `incomplete` | يُحوَّل لإكمال بيانات المنظمة (`/onboarding`) |
| 5 | `ops@masar.io` | `Passw0rd!` | فريق مسار | مشرف المنصة (platform operator) | بدون منظمة — `is_platform_admin` | شاشة المشغّل: مراجعة المنظمات والموافقة/الرفض/الإيقاف (`/operator`) |

## المشاريع التجريبية

كل طلب ومهمة ومجلد وملف وتقرير وسجل MEAL في بيانات التجربة تابع لأحد مشروعين في «منظمة النور» (المشروع إلزامي):

| الرمز | الاسم | الحالة | الفريق |
|---|---|---|---|
| `PRJ-001` | مشروع ألف | `active` | جلال العمر (`member`)؛ مدير النظام يراه لأن له وصولاً كاملاً |
| `PRJ-002` | مشروع باء | `active` | جلال العمر (`member`)؛ مدير النظام يراه لأن له وصولاً كاملاً |

ولا يوجد مشرف مشروع (`supervisor`) في بيانات التجربة؛ لتجربة الموافقة على طلب بحساب غير مدير النظام، عيّن مشرفاً من صفحة المشروع ← «تعديل الفريق».
الموظفون الأربعة بلا تسجيل دخول ليسوا في أي فريق.

## كيف أحصل على هذه الحسابات؟

```bash
# Backend الحقيقي (المنفذ 4010)
cd backend
npm run seed        # يُنشئ البيانات (idempotent — لا يفعل شيئاً إذا admin@org.org موجود)
npm run db:reset    # يمسح كل شيء ويعيد البناء (للتطوير فقط)
npm run dev

# أو الـ Mock backend (بدون قاعدة بيانات)
cd frontend
node scripts/mock-backend.mjs
```

وفي الفرونت (`frontend/.env.local`): `API_URL=http://localhost:4010` ثم `npm run dev` (المنفذ 3000).

## إنشاء مشغّل منصة جديد (للإنتاج)

لا تعتمد على `ops@masar.io` في الإنتاج. أنشئ مشغّلاً بالـ CLI:

```bash
cd backend
PLATFORM_ADMIN_PASSWORD='<كلمة-مرور-قوية>' npm run cli -- create-platform-admin --email you@company.com --name "Name"
# بدون المتغير تُولَّد كلمة مرور وتُطبع مرة واحدة فقط
```

## شروط كلمة المرور

8–128 حرفاً، مع رقم واحد على الأقل ورمز خاص واحد على الأقل (مثل `Passw0rd!`).
